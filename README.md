# Health Prediction Application

A small health prediction application built for the Junior AI/ML Developer task.

## Tech Stack

- Python
- Streamlit (UI + backend)
- SQLite (persistent storage)
- Simple rule-based AI risk model (to be added)

## Setup

1. Create and activate a virtual environment (optional but recommended).
2. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

3. Run the app:

```bash
python -m streamlit run app.py
```

The app will open in your browser at the local Streamlit URL.
